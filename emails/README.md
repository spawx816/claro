# Carpeta de Correos Recibidos (Incoming Emails)

¡Hola! Esta carpeta ha sido creada para que puedas guardar aquí los correos que te vayan llegando. 

### ¿Cómo funciona?
1. Crea un archivo de texto plano (por ejemplo: `correo1.txt`, `mantenimiento.txt`, `promocion.eml`) dentro de esta carpeta.
2. Pega el contenido completo del correo (Asunto, Remitente y Cuerpo) en ese archivo y guárdalo.
3. Avísame por el chat diciéndome algo como *"Ya guardé el correo en la carpeta"* o *"Procesa el archivo correo1.txt"*.
4. Yo leeré el archivo, analizaré su contenido con Inteligencia Artificial, y te diré cómo se clasificará, o actualizaré la base de datos de comunicaciones de la aplicación directamente para ti.
